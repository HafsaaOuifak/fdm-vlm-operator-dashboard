FDM VLM Operator Dashboard

A guardrailed dashboard where a vision-language model looks at a 3D-print image, names the defect, and suggests corrective actions for an operator to approve.

1Get the project on your computer

You need Git and Python 3.10+. Open a terminal and run:

git clone https://github.com/HafsaaOuifak/fdm-vlm-operator-dashboard.git
cd fdm-vlm-operator-dashboard

No Git? On the GitHub page click Code → Download ZIP, unzip it, and open a terminal in that folder. To get later updates: git pull.

2Install (first time only)

Needs Python 3.10 or newer.

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

On Windows use .venv\Scripts\pip and .venv\Scripts\python instead.

3Download the example images (optional)

sh get_sample_frames.sh

Five example frames from the public FDM defect dataset of Hu et al. (2024). You can also upload your own PNG/JPG.

4Choose a model

GPT models (GPT-4.1, GPT-5.4, GPT-5.4 mini): copy the settings file and paste your OpenAI API key into it.

cp .env.example .env
# open .env and fill in OPENAI_API_KEY=...

.env holds your secret key. It is listed in .gitignore; never commit or share it.

Local models (free, offline): install Ollama, keep it open, and download a model once:

ollama pull llama3.2-vision

5Run

.venv/bin/python app_nicegui.py

Your browser opens http://localhost:8600. Press Ctrl + C in the terminal to stop.

6Use it

  • Click Browse to upload an image, or pick a Benchmark specimen.
  • Pick a model, adjust the machine and process values if needed.
  • Click Run diagnostics. You get the defect, confidence, root cause, six safety checks, and the actions released for your approval.
  • Click Export audit (.json) to save a record of the decision.

No API key or Ollama? Open the settings icon next to the model and switch on Demo / mock mode to try the interface with scripted answers.

?Troubleshooting

  • "No API key found": check .env exists and has your key, then restart the app.
  • "Cannot connect to Ollama": open the Ollama app (or run ollama serve) and retry.
  • Port already in use: run on another port with MONITOR_PORT=8601 .venv/bin/python app_nicegui.py.

Recommendations are advisory only: the dashboard never controls the printer, and every action needs operator approval.
